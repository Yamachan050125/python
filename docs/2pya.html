制御構文１ 条件分岐

Python勉強会

作者

とりけらとっぷす

条件文とは、条件が満たされているかによって、コードの一部が実行されるかを決定するコードのこと(R.Payne ほか 2021年)である。

この文を作るには、極めて論理的なコードを構築する必要がある。これこそが、小学校でプログラミング教育でも重視されている「論理的思考力」の育成に繋がる。

まずは、R.Payne ほか (2021年) の例を引用し、条件文をコードを使わずに説明する。

疑似コードでイメージをつかもう

あなたは今ランチを食べようとしている。筋肉を鍛えるためのランチにしたい。ランチボックスの中身は以下の通り。

  • パン×２
  • ザクザクピーナッツバター
  • なめらかピーナッツバター
  • アップルジャム
  • グレープジャム
  • ストロベリージャム

パンは使用するとしても、どれをつけるかは判断が必要になる。これが条件文である。

もし, サンドイッチを作るならば：
    パンを取得
次に, ピーナッツバターの種類を選択.
もし, ピーナッツバターのタイプ = "なめらか" ならば：
    "気持ち悪い. 気持ち悪いからやめろよ"と表示.
違うならば：
    "ザクザクは正しい選択だよ！　ウマい！"と表示.
次に, ジャムの種類を選択.
もし, ジャムの種類 = "グレープ" ならば：
    "選ぶのが苦手なのかい？"と表示.
違うならば,  もし, ジャムの種類 = "ストロベリー" ならば：
    "ピーナッツバターを台無しにしたいなら, どうぞ"と表示.
違うならば, もし, ジャムの種類 = "アップル" ならば：
    "アップルジャムで決まりだね！　一番おいしいよ！　君は賢いね！"と表示.
次に, パンにピーナッツバターとジャムを塗り, はさんで, 耳をとって, 食べる.

となるわけである。これをコードでやるだけ。まずは、「もし」を使った条件文ifの書き方を学ぶ。

条件分岐

ifは、与えられた条件がTRUEかFALSEかによって実行すべき処理を決める命令(山田 2020年)である。日本語に直すと、「もしも～だったら…、違うならば…」である。

単純分岐

まずは、「違うならば…」が１つしかないものから始めよう。構文は以下の通り。

if 条件式:
    条件式がTrueのときに実行する処理
else:
    条件式がFalseのときに実行する処理

では、変数iが、3であるか否かを判定するコードを書いてみよう。

#もしiが3のとき
i = 3 #i=3と定義する

if i == 3:                      #もしiが3であるならば
    print("iは3じゃボケ！！！")  #「iは3じゃボケ！！！」と表示する
else:                           #もしiが3でないならば
    print("iは3じゃねーよ")      #「iは3じゃねーよ」を表示する
iは3じゃボケ！！！
#もしiが3でないとき
i = 5 #i=5と定義する

if i == 3:                      #もしiが3であるならば
    print("iは3じゃボケ！！！")  #「iは3じゃボケ！！！」と表示する
else:                           #もしiが3でないならば
    print("iは3じゃねーよ")      #「iは3じゃねーよ」を表示する
iは3じゃねーよ
ノート

ちなみに、if文のように、配下に複数の文を持ち、それらの文を実行するかどうかを決めるための文(山田 2020年)のことを複合文と呼ぶ。複合文は、一つ以上の節から構成され、節内には、ヘッダーとスイート（ブロック）がある。

警告

以下の文法に注意せよ。

  • 一つの複合文でヘッダーのインデント（字下げ位置）はそろっていること
  • ヘッダーを識別するキーワード（if, elseなど）で始まり、コロン:で終わること

ブロックを示すインデントは半角空白4つを使おう。Tabキーはでも可能であるが、エディタによって表示が違うので、Tabキーは原則使用しないこと。

if i == 10
----print("iは10である") #-は半角空白に置き換える

なお、elseを省略した場合、if文で書いた条件時だけ、ブロックの内容が実行される。

i = 3
if i == 3:
    print("3だぜ( ｰ`дｰ´)ｷﾘｯ")
#elseを省略する。
#つまり「3か。3以外か。」-GAKUT
3だぜ( ｰ`дｰ´)ｷﾘｯ

多岐分岐

多岐分岐は、「も～なら」が何個もある場合の文を作ることができる。その際は、elifを用いる。

構文は以下の通り

if 条件式１:
    条件式１がTrueの時に実行する処理
elif 条件式２:
    条件式２がTrueの時に実行する処理
...
else:
    上記条件にすべて当てはまらない場合の処理

elifは、条件の数だけ増やせる。すなわち、ifは１つ且つ一番最初のみ使用。増やしたいときは、elifを使用する。

変数iが、3以上であるか、4以上であるか否かを判定するコードを書いてみよう。

i = 5

if i > 3:
    print("iは3より大きいよ")
elif i > 4:
    print("iは2より大きいよ")
else:
    print("変数は1以下だよ") 
iは3より大きいよ
重要

ここで大事なのは、if文は、複数の条件に合致しても、実行されるブロックは最初に合致した１つ目のブロックのみであることに注意しなければならないことである。そのため、上記例では、

elif i > 4:
    print("iは2より大きいよ")

が、条件に当てはまるのに実行されなかった。

入れ子のif文

if文は、互いに入れ子（ネスト）構造にできる。

i = 3
j = 0

if i == 3:                                  #外側のif命令start
    if j == 3:                              #内側のif命令start
        print("変数iもjも3である")
    else:
        print("変数iは3ですが、jは3ではない") #内側のif命令finish
else:                                       #外側のif命令finish
    print("変数iは3ではない")
変数iは3ですが、jは3ではない

このとき、当然だが同じ階層のヘッダー／ブロックはインデントを揃えることが重要である。

論理積and

論理演算子and（演算子の左辺と右辺の値がともに「true」の場合だけ、全体がtrue）も使用可能

if 条件式１ and 条件式２:
    処理

この場合、もし条件式１が合っている、かつ、条件式２が合っていたら処理を行うとなる。

論理和or

論理演算子or（演算子の左辺または右辺の値が少なくとも1つがtrueの場合に、全体がtrue）も使用可能

if 条件式１ or 条件式２:
    処理

この場合、もし条件式１または条件式２のどちらかが合っていたら処理を行うとなる。

論理否定 not

否定文にしたいときは、notを使用する。

if not 条件式:
    処理
重要

ただし、条件式からは、なるべく否定表現を使用しないことが重要である。

というのは、論理演算子は、時として思わぬバグの温床となる。特に、否定＋論理演算子は、一般的に混乱の元であり、なるべく肯定表現へ置き換えるが、このとき使用するのが、ド・モルガンの法則である。

コードで書くなら

not A and not B = not(A or B)

not A or not B = not(A and B)

である。

例えば、

if not A and not B:
    ~
